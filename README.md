# Slutprojekt Drinkhanterare

A drink management application built with C# and .NET.

## Overview

This project is a drink handler/manager application developed as a final project. It provides functionality for managing and organizing drink-related data and operations.

## Requirements

- **.NET 8** or later

Make sure you have .NET 8 installed before running this project. You can download it from [dotnet.microsoft.com](https://dotnet.microsoft.com/download).

## Project Notes

- **Language**: C#
- **Code Comments**: Swedish (Svenska) - Comments throughout the codebase are written in Swedish
- **Status**: This is a final project and is not planned for future fixes or updates

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alexandrosmuller19-ux/Slutprojekt-cs.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Slutprojekt
   ```

3. Build the project:
   ```bash
   dotnet build
   ```

4. Run the application:
   ```bash
   dotnet run
   ```
